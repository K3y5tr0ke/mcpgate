## 1. What Was Implemented

Sprint 2 closes the unauthenticated gap left at the end of Sprint 1. All MCP proxy routes (`/mcp/*`) and admin routes (`/api/v1/admin/*`) were completely open — any client could call any endpoint. This sprint delivers:

- **SAML 2.0 SP-initiated login** via `github.com/crewjam/saml` (redirect binding login, POST binding ACS, metadata endpoint, logout)
- **RS256 JWT session tokens** via `github.com/golang-jwt/jwt/v5` with dev-mode ephemeral key fallback
- **Postgres-backed session storage** (durable source of truth) and **Redis session cache** (fast auth path)
- **Auth middleware** applied to all protected routes, with bearer-token and cookie extraction, session liveness check, and optional sliding expiry
- **JIT user provisioning** during SAML ACS — new users are created automatically on first login
- **Replay detection** via Redis `SET NX` on SAML assertion IDs
- **Admin REST CRUD** for IdP configurations (`/api/v1/admin/idps`)
- **Full Postgres store implementations** for `users`, `sessions`, `roles`, and `saml_idp_configs` tables

The binary remains runnable with `make dev`. With no signing key configured, a fresh RSA-2048 key is generated in memory and a warning is logged. No new database migrations were needed — all tables were defined in Sprint 0.

## 3. Store Additions (`internal/store/interfaces.go`)

### 3.1 `SAMLIDPConfig` Struct

```go
type SAMLIDPConfig struct {
    ID           uuid.UUID
    Name         string
    EntityID     string
    SSOURL       string
    SLOURL       *string           // nullable — SLO not required
    Certificate  string            // PEM X.509
    AttributeMap map[string]string // JSONB — IdP attr name → internal field name
    GroupRoleMap map[string]string // JSONB — IdP group name → role name
    IsEnabled    bool
    CreatedAt    time.Time
    UpdatedAt    time.Time
}
```

`SLOURL` is a `*string` (nullable) because SLO is optional in SAML 2.0. `AttributeMap` and `GroupRoleMap` are `map[string]string` — they map to JSONB columns and are marshalled/unmarshalled with `encoding/json`.

### 3.2 `SAMLIDPConfigStore` Interface

```go
type SAMLIDPConfigStore interface {
    Create(ctx context.Context, cfg *SAMLIDPConfig) error
    GetByID(ctx context.Context, id uuid.UUID) (*SAMLIDPConfig, error)
    GetByName(ctx context.Context, name string) (*SAMLIDPConfig, error)
    List(ctx context.Context) ([]SAMLIDPConfig, error)
    ListEnabled(ctx context.Context) ([]SAMLIDPConfig, error)
    Update(ctx context.Context, cfg *SAMLIDPConfig) error
    Delete(ctx context.Context, id uuid.UUID) error
}
```

`ListEnabled` filters to `is_enabled = true` and orders by `name`. It is used at SP init time to discover configured IdPs.

## 5. JWT Manager (`internal/auth/jwt/manager.go`)

### 5.1 Claims

```go
type Claims struct {
    jwt.RegisteredClaims         // sub, iss, iat, exp
    Email     string   `json:"email"`
    Roles     []string `json:"roles"`
    SessionID string   `json:"session_id"`
}
```

`Roles` in the JWT are **informational only**. The auth middleware fetches roles from `SessionData` (the Redis cache), which is authoritative. This allows role changes to take effect without requiring users to log in again — the session data can be updated while the JWT remains valid.

### 5.2 Key Loading

`NewManager` reads a PEM file specified by `cfg.SigningKeyFile`. It tries PKCS8 parse first, then PKCS1 as a fallback (supporting both `openssl genpkey` and `openssl genrsa` output). If `SigningKeyFile` is empty, a fresh RSA-2048 key pair is generated in memory and a `WARN` message is logged:

```
WARN: using ephemeral JWT signing key — tokens will not survive restart
```

This makes `make dev` work without running `scripts/generate-certs.sh` first.

### 5.3 TTL Handling

The `ttl == 0` check (not `<= 0`) is intentional. Integration tests can pass a negative TTL (`-time.Hour`) to generate an already-expired token for testing. A zero TTL falls back to the configured `AccessTokenTTL`. A negative TTL is forwarded as-is.

### 5.4 Tests (`manager_test.go`)

| Test | What It Verifies |
|------|-----------------|
| `TestIssueAndValidate` | Round-trip: issued token validates correctly, claims match |
| `TestValidateExpiredToken` | Token with `-time.Hour` TTL → error on validate |
| `TestValidateTamperedToken` | Entire signature segment replaced with `AAAA…` → error |
| `TestValidateWrongIssuer` | Different issuer in second manager → error |
| `TestValidateMalformed` | Random string → error |

The tamper test replaces the entire third JWT segment (the signature) rather than flipping a single byte. Flipping a single byte of a base64url-encoded signature can accidentally produce valid base64url that still decodes correctly to a wrong-but-parseable byte sequence — replacing the whole segment is reliable.

## 6. Auth Middleware (`internal/auth/middleware.go`)

### 6.1 `TokenValidator` Interface

```go
type TokenValidator interface {
    Validate(tokenString string) (*jwtpkg.Claims, error)
}
```

Defined in `middleware.go` rather than the `jwt` package to keep `jwt` free of HTTP concerns. `*jwt.Manager` satisfies it. Tests use a `mockValidator`.

### 6.2 `Authenticate` Middleware

**Token extraction order:** `Authorization: Bearer <token>` header first, `mcpgate_session` cookie second.

**Middleware logic (in order):**
1. Extract token string → 401 `authentication required` if absent
2. `validator.Validate(token)` → 401 with `token expired` or `invalid token` on failure
3. Parse `claims.SessionID` as UUID → `sessionCache.Get()` → 401 `session expired or revoked` on miss
4. Build `UserIdentity` from `SessionData` — roles come from the cache, not JWT claims
5. If `cfg.SessionSliding`: call `sessionCache.Extend()` in a goroutine (non-blocking)
6. `next.ServeHTTP(w, r.WithContext(auth.WithIdentity(ctx, identity)))`

**`writeAuthError`** always writes HTTP 401. The `status` parameter was removed during the lint pass (unparam: the function was always called with `http.StatusUnauthorized`).

### 6.3 Tests (`middleware_test.go`)

Six table-driven tests using `mockValidator` and `mockSessionCache`:

| Test | Expected Result |
|------|----------------|
| No token | 401 |
| Valid token + valid session | 200, `next` called with identity in context |
| Cookie token (no header) | 200, `next` called |
| Invalid token (validator returns error) | 401 |
| Expired token | 401 with `token expired` body |
| Session cache miss | 401 with `session expired or revoked` body |

## 7. SAML Package (`internal/auth/saml/`)

### 7.1 Attribute Mapper (`attribute_map.go`)

```go
type MappedAttributes struct {
    Email       string
    DisplayName string
    Groups      []string
}

func Extract(assertion *saml.Assertion, mapping map[string]string) MappedAttributes
```

`Extract` matches IdP attribute statements in the following priority order:

1. **FriendlyName match** — matches the human-readable attribute name (e.g., `email`, `displayName`)
2. **Name match** — matches the full URN or OID (e.g., `urn:oid:0.9.2342.19200300.100.1.3`)
3. **NameID fallback** — if no email attribute is found, `assertion.Subject.NameID.Value` is used as the email

Multi-valued group attributes are collected into a `[]string`. Tests cover all three resolution paths plus the empty-assertion edge case.

### 7.2 SP Wrapper (`sp.go`)

```go
type SP struct {
    configured bool
    cfg        config.SAMLConfig
    idpStore   store.SAMLIDPConfigStore
    logger     *slog.Logger
    privateKey crypto.Signer
    cert       *x509.Certificate
}
```

`NewSP` attempts to load the key pair from the file paths in `cfg`. If both paths are empty, a fresh RSA-2048 key + self-signed certificate are generated in memory (same ephemeral strategy as JWT). `configured` is set to `false` when no IdP metadata is available — all handlers gate on `sp.Configured()` and return 503 rather than panicking.

**`NewServiceProvider(idpCfg *SAMLIDPConfig) (*cssaml.ServiceProvider, error)`** — builds a `cssaml.ServiceProvider` struct from a database-stored IdP config. The IdP metadata is constructed in-memory from the `EntityID`, `SSOURL`, `SLOURL`, and `Certificate` fields. This avoids requiring an IdP metadata XML URL and allows the IdP cert to be stored in the database.

**`buildIDPMetadata`** — constructs a `*cssaml.EntityDescriptor` from struct fields. Notable detail: the certificate is stored in the IdP config as PEM; it must be DER-decoded and then base64-encoded for the `KeyDescriptor.X509Data[0].Data` field in the metadata struct.

**`SPMetadata() (*cssaml.EntityDescriptor, error)`** — generates SP metadata from the SP's own key and configured ACS/metadata URLs. Works even when `configured == false`.

### 7.3 Handlers (`handlers.go`)

All four handlers are methods on `Handlers`, constructed via `NewHandlers(...)` with all dependencies injected.

#### `Login` — GET /auth/saml/login

1. Checks `sp.Configured()` → 503 if not
2. Fetches the first enabled IdP from the store
3. Calls `NewServiceProvider(idpCfg)` to build a per-request SP
4. `sp.MakeAuthenticationRequest(ssoURL)` → builds a SAML `AuthnRequest`
5. Sets `RelayState` from `redirect_to` query param (defaults to `/`)
6. `authReq.Redirect(relayState, sp)` → HTTP redirect to IdP SSO URL

#### `ACS` — POST /auth/saml/acs

1. Fetches enabled IdP from store → builds SP → `sp.ParseResponse(r, []string{})` (validates signature, audience, time conditions)
2. **Replay detection**: `SET saml:replay:<assertionID> "1" EX <ttl> NX` on Redis; if key existed → 400 `assertion already consumed`. TTL = `(NotOnOrAfter − now) + 5 minutes` (clock skew buffer). If Redis is unavailable, replay check is skipped (availability over strict prevention)
3. `Extract(assertion, attributeMapping)` → email, displayName, groups
4. **JIT provisioning** (see §7.4)
5. `user.Status != "active"` → 403 `account suspended`
6. `roleStore.GetUserRoles(ctx, user.ID)` → role name slice
7. Create `store.Session` in Postgres, cache `SessionData` in Redis with `cfg.Auth.SessionTTL`
8. `jwtManager.Issue(user.ID, user.Email, roles, session.ID)` → token string
9. Set `mcpgate_session` cookie: `HttpOnly; Secure; SameSite=Lax`
10. If `RelayState` is a relative path (starts with `/`): redirect. Otherwise: return JSON `{"token": "<token>"}`

#### `Metadata` — GET /auth/saml/metadata

Returns XML SP metadata. Works even when no IdP is configured — useful for giving admins the SP metadata to register in their IdP before configuring the IdP in mcpgate.

#### `Logout` — GET /auth/saml/logout

1. Extracts JWT from cookie/header; parses it (ignoring expiry — a just-expired token should still allow logout)
2. Deletes session from Redis cache and Postgres
3. Clears `mcpgate_session` cookie (`MaxAge=-1`)
4. Redirects to `/`

### 7.4 JIT User Provisioning

```
GetByIDPSubject(idpName, nameID)
  → found: update DisplayName if changed → use existing user
  → ErrNotFound:
      GetByEmail(email)
        → found: set IDPSubject + IDPName → Update() → use existing user
        → ErrNotFound: Create() new user with Status="active"
```

Email-first lookup handles the case where a user was manually created in the admin UI before their first SAML login — the IdP subject is back-filled on first login.

### 7.5 Integration Tests (`handlers_test.go`, `//go:build integration`)

Uses `github.com/crewjam/saml/samlidp` as an in-process test IdP — no SimpleSAMLphp container required.

**Test IdP setup:** `samlidp.New()` creates a `samlidp.Server` with a `MemoryStore`. The SP entity descriptor is registered via `idpStore.Put("/services/<entityID>", spMeta)`. The `samlidp.Server` acts as the `ServiceProviderProvider` for the underlying `IdentityProvider` (via its `GetServiceProvider` implementation).

**Synthetic SAML response construction** (`buildSAMLResponse`):
```go
req := &cssaml.IdpAuthnRequest{IDP: idp, ...}
assertionMaker := cssaml.DefaultAssertionMaker{}
assertionMaker.MakeAssertion(req, session)
req.MakeAssertionEl()
req.MakeResponse()
form, _ := req.PostBinding()
// form.SAMLResponse is base64-encoded, ready for POST to ACS
```

This approach bypasses the browser flow entirely and produces a fully signed SAML response.

| Test | Scenario | Expected |
|------|----------|---------- |
| `TestACS_NewUserJITProvision` | POST signed assertion for unknown user | 200/302; user row created with `status=active` |
| `TestACS_ReplayDetection` | POST same assertion twice | First: 200/302; Second: 400 |
| `TestACS_SuspendedUser` | POST assertion for pre-created `status=suspended` user | 403 |

## 8. Postgres Store Implementations

### 8.1 `UserStore` (`users.go`)

| Method | Notes |
|--------|-------|
| `Create` | `RETURNING` all columns; unique violation (pgconn `"23505"`) → `ErrAlreadyExists` |
| `GetByID` | UUID param; `ErrNoRows` → `ErrNotFound` |
| `GetByEmail` | Case-sensitive; `ErrNoRows` → `ErrNotFound` |
| `GetByIDPSubject` | `WHERE idp_name = $1 AND idp_subject = $2` |
| `Update` | Checks `RowsAffected() == 0` → `ErrNotFound` |
| `List` | Dynamic WHERE from `UserFilter` fields using positional params |

**Dynamic WHERE construction:** Parameters are accumulated in an `args []any` slice alongside a `conditions []string` slice. Final clause: `strings.Join(conditions, " AND ")`. Pagination appended as final two params after the WHERE clause — args slice is extended in place (`args = append(args, page.PageSize, offset)`).

**JSONB `metadata` column** — marshalled to `[]byte` for write; scanned to `[]byte` then unmarshalled on read.

**Unique violation detection:**
```go
func isUniqueViolation(err error) bool {
    var pgErr *pgconn.PgError
    return errors.As(err, &pgErr) && pgErr.Code == "23505"
}
```

### 8.2 `SessionStore` (`sessions.go`)

| Method | Notes |
|--------|-------|
| `Create` | `client_ip` is INET in Postgres — inserted as `$n::inet` (text cast) |
| `GetByID` | Selects `client_ip::text` (cast to text for scanning) |
| `DeleteByUserID` | Bulk-delete all sessions for a user (forced logout) |
| `DeleteExpired` | `DELETE WHERE expires_at < now()`; returns `RowsAffected()` |

The `client_ip::text` / `$n::inet` pattern is required because pgx v5 does not have a native Go ↔ `INET` type mapping — passing text strings with explicit SQL casts is the idiomatic solution.

### 8.3 `RoleStore` (`roles.go`) — Sprint 2 Stub

Only `GetUserRoles(ctx, userID)` is implemented, querying `user_roles JOIN roles ON roles.id = user_roles.role_id WHERE user_roles.user_id = $1`. All other methods (`Create`, `Update`, `Delete`, `List`, `AssignToUser`, `RemoveFromUser`) return:
```
fmt.Errorf("roles: <method> not implemented — Sprint 4")
```

Full RBAC implementation is planned for Sprint 4.

### 8.4 `SAMLIDPConfigStore` (`saml.go`)

| Method | Notes |
|--------|-------|
| `Create` | JSONB `attribute_map`/`group_role_map` marshalled to `[]byte` |
| `GetByID` / `GetByName` | JSONB columns scanned to `[]byte` then unmarshalled |
| `List` | `ORDER BY name` |
| `ListEnabled` | `WHERE is_enabled = true ORDER BY name` |
| `Update` | Full replace; checks `RowsAffected()` |
| `Delete` | Checks `RowsAffected()` |

`slo_url` is a nullable text column; scanned to `*string` (nil when `NULL`).

## 9. Redis Session Cache (`internal/store/redis/session_cache.go`)

```
Key format:  session:<sessionID-as-string>
Value:       JSON-encoded store.SessionData
TTL:         set at creation; extended on each request when SessionSliding = true
```

| Method | Behaviour |
|--------|-----------|
| `Set` | `json.Marshal` → `client.Set` with TTL |
| `Get` | `client.Get` → `json.Unmarshal`; `redis.Nil` → `store.ErrNotFound` |
| `Delete` | `client.Del` |
| `Extend` | `client.Expire`; returns error if key no longer exists (session was deleted) |

`store.ErrNotFound` (not raw `redis.Nil`) is returned on cache miss so callers use `errors.Is` uniformly across Postgres and Redis stores.
